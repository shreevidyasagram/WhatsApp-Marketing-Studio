# WhatsApp Marketing Studio — Shree Vidyasagram

A dashboard prototype for managing opted-in customer contacts and preparing WhatsApp marketing campaigns.

## Status
This repository currently contains a front-end prototype. It does not send WhatsApp messages or connect to the WhatsApp Business Platform yet. Before production use, add a secure server-side integration with Meta's official WhatsApp Business Platform and use approved templates and customer opt-in.

## Publish with GitHub Pages
After adding `index.html`, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
